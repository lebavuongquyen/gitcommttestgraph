# 0.10.2 RCV01 — Consistency Checker

Date: 2026-10-07
Status: IMPLEMENTED

## Goal

RCV01 verifies that GCTG-owned snapshot metadata and physical snapshot objects agree before any recovery or cleanup action relies on them.

## Checks

- malformed manifest;
- invalid manifest entries;
- duplicate logical snapshot identity;
- manifest entries whose physical object is missing;
- corrupt or schema-invalid physical objects;
- orphan physical JSON objects;
- temporary snapshot artifacts indicating incomplete write or cleanup.

## Safety

The checker is strictly read-only.

It never deletes or repairs an object and never modifies Git history.

An unhealthy result is evidence for later recovery work; it is not permission to guess a repair.

## Surfaces

HTTP: GET /api/consistency-check

MCP: consistency_check

## Scope boundary

RCV01 does not repair, rehydrate, restore or delete data.

Those actions remain later recovery milestones.

## Tests

Coverage includes application reporting plus direct storage detection for missing, corrupt and orphan objects.

## Definition of Done

- [x] manifest consistency is checked;
- [x] duplicate identities are detected;
- [x] missing objects are detected;
- [x] corrupt objects are detected;
- [x] orphan objects are detected;
- [x] incomplete temporary artifacts are detected;
- [x] checker is read-only;
- [x] HTTP and MCP surfaces exist;
- [x] tests and documentation exist.
