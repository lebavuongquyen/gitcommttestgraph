## Scope

0.9.3 adds deterministic historical intelligence over the existing commit-scoped graph snapshot architecture.

It answers:
- what semantic symbols changed between commits;
- when dependency relationships were added or removed;
- when a test became or ceased to be impacted;
- which Git commits and graph evidence support the transition.

## Safety and correctness

Historical Intelligence never substitutes the current working tree for a requested historical commit.

The service fails closed when the requested history window exceeds the configured maxCommits bound.

Short and full Git references are canonicalized before sequence construction, preventing duplicate commit entries.

Merge commits are represented with all parents and produce explicit uncertainty rather than an invented single-parent explanation.

Symbol rename/move lineage is not claimed unless deterministic identity evidence supports it.
