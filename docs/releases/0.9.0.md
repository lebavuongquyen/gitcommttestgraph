# Release 0.9.0

Date: 2026-10-06

## Stable Public API

0.9.0 establishes the first supported programmatic API boundary for GCTG.

### Supported entrypoint

Consumers should import the stable programmatic surface from:

git-commit-test-graph/api

The package root remains available for the legacy 0.8-compatible surface.

### Stable contracts

The public contract registry provides runtime validation for:

- graph snapshots;
- change intelligence;
- impact results;
- test impact;
- execution plans;
- evidence;
- public errors.

Public API version: 1.0.0.

### Compatibility policy

Within public API version 1:

- additive fields are compatible;
- required fields and their meanings are stable;
- removing or renaming a public field requires a major public API version;
- versioned payloads must carry their schema version;
- unsupported future schema versions fail closed;
- internal implementation modules are not compatibility promises.

### Package strategy

0.9.0 intentionally does not split the project into @gctg/core, @gctg/api or @gctg/mcp.

The exact package boundary remains a dependency-analysis decision for the post-1.0 product extraction phase.
