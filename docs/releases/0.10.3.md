# Release 0.10.3

## Release status

## What 0.10.3 delivers

Version 0.10.3 is a focused maintenance release for the real-project GUI validation stage.

- fixes a GUI crash caused by the graph renderer expecting an older graph-node shape than the public graph API returns;
- normalizes graph nodes in the GUI view-model layer from the public `type` and `attributes.kind/name/path` fields;
- adds regression coverage for the current public graph schema;
- improves desktop, tablet and mobile GUI layout behavior;
- removes fixed-height and fixed-column assumptions that could clip the workbench;
- keeps the existing GUI-first capability surface and 0.10.x architecture;
- hardens operation-history ordering when multiple operations share the same timestamp;
- does not introduce the deferred 0.11 architectural refactor.

## Root cause

The public graph API returns nodes using a transport shape such as:

```json
{
  "type": "Symbol",
  "attributes": {
    "kind": "function",
    "name": "App",
    "changed": true
  }
}
```

The GUI adapter previously looked for `node.kind` and `node.label` directly. The resulting empty presentation fields caused the graph renderer to call string operations on an empty kind value and the browser UI stopped rendering the loaded repository state.

The fix keeps this translation inside the GUI view-model boundary.

## Responsive behavior

- Desktop: three-panel workbench.
- Medium screens: inspector moves below the graph.
- Mobile screens: commits, graph and inspector stack vertically.
- Header controls wrap instead of forcing horizontal overflow.
- The page can scroll vertically instead of being clipped to the viewport.
