# Release 0.7.1

Date: 2026-10-06

## Purpose

0.7.1 is a correctness and reliability hardening release for Pull Request Intelligence. It adds no new product capability; it makes the 0.7.0 PR analysis trustworthy for real GitHub workflows.

## Fixed

- PR analysis now uses immutable GitHub base/head SHAs instead of mutable branch names.
- Fork PRs resolve the exact head repository and fetch the exact head commit when it is not already local.
- GitHub fetch authentication can use GITHUB_TOKEN through Git HTTP configuration without placing the token in command arguments.
- Review state is calculated from the latest review per reviewer instead of sticky historical states.
- Review evidence preserves reviewer, state, submitted time and review commit SHA.
- Approval freshness is checked against the current PR head SHA.
- GitHub review pagination is supported.
- GitHub check-run pagination is supported.
- Pagination has a bounded safety limit.
- Removed-symbol downstream impact is resolved from the base graph.
- PR review semantics distinguish current-head approval from stale approval.
- PR review reports uncertainty instead of claiming GitHub branch-protection requirements are satisfied when that information is unavailable.
- HTTP and MCP PR review paths now use the same immutable-SHA/base-graph analysis.
- Repository identifier validation was tightened.
