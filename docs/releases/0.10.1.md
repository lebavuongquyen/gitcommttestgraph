# Release 0.10.1

## Release status

**Status:** Released - npm and Git tag publication completed

**Milestone:** 0.10.x maintenance

**Audience:** Fresher, Junior, Developer, Reviewer, CI/Agent integrator

## What 0.10.1 delivers

Version 0.10.1 is a maintenance patch for the 0.10 hardening line.

- removes developer-machine-specific paths from user-facing documentation;
- provides the first-user guide in English and Vietnamese;
- normalizes visible documentation encoding artifacts;
- hardens RCV03 and RCV04 MCP contract tests against slow Windows process startup;
- improves index-lock recovery so locks owned by dead processes can be reclaimed immediately;
- increases the Windows HTTP contract-server startup allowance to reduce false failures on slower developer machines;
- preserves the existing 0.10 runtime, GUI, HTTP, MCP and public API behavior;
- does not introduce the deferred 0.11 architectural refactor.
