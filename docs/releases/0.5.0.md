# Release 0.5.0

Date: 2026-10-05

## Release goal

Turn the existing deterministic execution-plan capability into a GUI-first execution workflow without duplicating business logic outside the application/domain layer.

## Delivered

- Visual execution panel in the local GUI.
- Deterministic impacted-test plan displayed as ordered runnable steps.
- Explicit user confirmation before test execution.
- HTTP execution boundary for the GUI.
- Persisted execution feedback reused by the GUI.
- Per-step runtime status and command visibility.
- GUI execution backed by the same ExecutionPlanRunner and runtime-feedback services already exposed through MCP.
- Analyzer version now follows the package version.

## MCP alignment

The feature uses the existing MCP capabilities:

- `execution_plan` builds the deterministic plan.
- `run_execution_plan` performs the explicit side-effecting execution.
- `execution_feedback` reads persisted runtime feedback.

No business logic was moved into the GUI. The GUI HTTP endpoint is an adapter over the same application/domain execution path.
