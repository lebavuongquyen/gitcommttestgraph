# Release 0.9.7 — Compatibility Freeze

Date: 2026-10-06

## Status

PLANNED — compatibility-freeze milestone. This note is created so the release gate can validate the current 0.9.6 release boundary.

## Scope

The 0.9.7 milestone will freeze and verify the supported 0.9.x compatibility surface before the mandatory 0.9 → 0.10 architecture re-audit.

Planned checks:

- public API compatibility;
- CLI compatibility;
- HTTP compatibility;
- MCP tool/schema compatibility;
- GUI surface continuity;
- persisted snapshot/config compatibility;
- schema-version fail-closed behavior;
- package exports and SDK preview boundary;
- documentation consistency;
- release-gate evidence.

No new feature should be added merely to satisfy the compatibility freeze.

## Boundary

The mandatory 0.9 → 0.10 architecture re-audit remains after 0.9.7. Findings will be classified as CONFIRMED, MERGED, DEFERRED, REMOVED or NEW before the 0.10 roadmap is finalized.
