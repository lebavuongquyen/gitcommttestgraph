## Repository Ecosystem

0.9.1 adds an explicit repository ecosystem capability layer.

It detects and reports:

- npm, pnpm, yarn and bun;
- TypeScript and JavaScript;
- Node test, Jest, Vitest, Playwright and generic test scripts.

Every capability contains support status, confidence, evidence and an explanation.

Unknown or unsupported ecosystems are reported as UNKNOWN. They are never silently treated as supported or converted into positive impact intelligence.
