## CI provider model

CI integration is provider-neutral. GitHub Actions and generic CI systems invoke the CLI and consume its exit code and JSON/SARIF output. No hosted service is required.

Example:

gctg ci COMMIT HEAD --format json

gctg ci BRANCH main HEAD --format sarif

A repository-installed workflow template is intentionally deferred to consuming repositories rather than coupling this engine to one CI provider.
