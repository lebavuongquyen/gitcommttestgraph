## Important live finding

The live repository currently exposes a node set without dependency edges. 0.11 therefore does not pretend that this is a valid dependency graph. The GUI explicitly reports that relationships are unavailable and presents the nodes as changed-code evidence.

This is a product-level data/graph-semantic issue that remains a 0.11 follow-up and is covered by the roadmap.
