# Release 0.8.0

Date: 2026-10-06

## Purpose

0.8.0 introduces Unified Change Intelligence as the first unified public capability across the Git change, graph, impact, test and execution layers.

The capability is deterministic and evidence-preserving. Public surfaces consume the same application contract.

## Added

- Unified Change Intelligence domain model.
- Unified change source normalization for commit and branch analysis.
- Change intelligence risk, reasons, uncertainty and evidence.
- Semantic graph diff integrated into the unified change result.
- Changed and removed symbol analysis.
- Downstream affected-symbol analysis.
- Test-gap and test-impact analysis.
- Deterministic execution-plan generation.
- CLI command gctg change-intelligence.
- HTTP endpoint /api/change-intelligence.
- MCP tool change_intelligence.
- GUI Change Intelligence cockpit.
- Public contract test framework.
- M04 executable Quality Gate.
- Mandatory Quality Gate development standard in docs/QUALITY-GATES.md.

## Quality Gate Standard

0.8.0 establishes:

> No Surface Without Gate.

Every externally exposed capability must have an executable quality gate for each exposed surface.

M04 gates cover domain/application semantics, CLI, HTTP, MCP, GUI, cross-surface consistency, regression and deterministic/reproducible behavior.

## Cross-surface contract

The same change input is analyzed through the same application service.

Serialization differs by surface, but semantic fields remain equivalent:

- source;
- base/head/merge-base;
- changed paths;
- changed symbols;
- removed symbols;
- affected symbols;
- risk;
- test-gap summary;
- test-impact summary;
- execution steps;
- reasons;
- uncertainty.
