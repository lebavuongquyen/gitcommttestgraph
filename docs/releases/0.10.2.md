# Release 0.10.2

## Release status

**Status:** Release candidate validation

**Milestone:** 0.10.x CLI distribution

**Audience:** Fresher, Junior, Developer, CI/automation user

## What 0.10.2 delivers

Version 0.10.2 completes the cross-platform `gctg` CLI distribution surface for the 0.10.x line.

- exposes `gctg` as the package's public npm/pnpm CLI command;
- makes `gctg --help`, `gctg -h` and `gctg help` successful help entry points;
- keeps `gctg --version` and `gctg -v` available;
- moves the TypeScript compiler runtime dependency into production dependencies because the semantic analyzer loads TypeScript at runtime;
- supports global installation through npm and pnpm;
- supports one-off execution through `npx --package git-commit-test-graph gctg ...` and `pnpm dlx --package git-commit-test-graph gctg ...`;
- adds a dedicated public CLI reference;
- adds permanent CLI help contract coverage;
- preserves the existing GUI, HTTP, MCP and public API architecture;
- does not introduce the deferred 0.11 architectural refactor.

## Installation

### npm

```bash
npm install -g git-commit-test-graph
gctg --version
gctg --help
```

### pnpm

```bash
pnpm add -g git-commit-test-graph
gctg --version
gctg --help
```

If pnpm reports that its global bin directory is not on PATH, run `pnpm setup` and restart the terminal.

### One-off

```bash
npx --package git-commit-test-graph gctg --version
pnpm dlx --package git-commit-test-graph gctg --version
```

The explicit `gctg` command is used because the package also exposes the separate `gctg-mcp` binary.
