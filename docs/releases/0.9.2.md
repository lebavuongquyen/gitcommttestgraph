## Monorepo Intelligence

0.9.2 adds a unified monorepo read model backed by the existing graph.

It reports:

- workspace boundaries;
- package dependencies and reverse dependents;
- package-level source ownership;
- package-specific test projects;
- package-level impact propagation;
- deterministic package topology.

No dependency is invented. Only verified `DEPENDS_ON` graph edges participate in package relationships and impact propagation.
