## What 0.10 delivers

Version 0.10 completes the operational foundation around GCTG-owned state:

- persistent configuration and operation history;
- health, diagnostics and failure classification;
- GUI workflow/state hardening;
- snapshot consistency checking;
- backup and restore;
- repair and rehydration;
- interrupted-operation recovery;
- a first-user documentation path that does not require prior GCTG knowledge.

The recovery capabilities are deliberately fail-closed and operate only on GCTG-owned state under ".gctg/". They do not rewrite Git history.

## User entry point

A first-time developer should **not** start by reading architecture or MCP documents.

Start here:

README.md → docs/GETTING-STARTED.md

Recommended first session:

```text
Build GCTG
   ↓
cd into a Git repository
   ↓
gctg status
   ↓
gctg serve 3717
   ↓
Open the printed local address
   ↓
Select a commit
   ↓
Inspect Changed / Affected
   ↓
Open Test impact
   ↓
Review Execution
```
