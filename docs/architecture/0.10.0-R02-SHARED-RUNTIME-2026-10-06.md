# 0.10.0 R02 — Shared Application Runtime

Date: 2026-10-06
Baseline: v0.9.8

## Objective

Remove duplicated repository graph-stack composition from CLI, HTTP and MCP surfaces.

## Runtime ownership

`ApplicationRuntime` owns:

- repository discovery;
- Git repository adapter;
- resolved configuration;
- graph store;
- semantic cache;
- full repository indexer;
- incremental indexer;
- index lock;
- analyzer version.

The runtime exposes the common operations required by surfaces:

- repository HEAD;
- commit indexing;
- configuration resolution;
- configuration update.

## Surface rule

CLI, HTTP and MCP adapters may construct feature/application services, but they must not construct the shared repository indexing stack themselves.

The following composition belongs only to the runtime:

- `RepositoryIndexer`;
- `IncrementalRepositoryIndexer`;
- `JsonGraphStore`;
- `JsonSemanticCache`;
- `IndexLock`;
- repository discovery;
- configuration store/service composition.

## Configuration lifecycle

Configuration updates pass through the runtime and update the runtime's effective configuration used by subsequent indexing operations.
