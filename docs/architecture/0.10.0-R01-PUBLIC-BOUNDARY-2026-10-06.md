# 0.10.0 R01 — Public Package Boundary

Date: 2026-10-06
Baseline: v0.9.8

## Objective

Make the package root a stable public SDK boundary without exposing infrastructure or surface implementation details.

## Decision

The supported package entrypoints are:

- `git-commit-test-graph`
- `git-commit-test-graph/api`

Both resolve to `dist/public/index.js`. Type declarations resolve to `dist/public/index.d.ts`.

The existing internal barrel remains an implementation composition entry for the CLI and MCP runtime. It is not part of the package export map.

## Boundary rules

- Public consumers import contracts and supported application capabilities only.
- Infrastructure adapters, persistence implementations, process execution and HTTP server internals are not package exports.
- Internal refactors must not change the supported SDK surface accidentally.
- The public API contract version remains 1.0.0.

## Verification

The 0.10.0 public-boundary contract verifies:

1. package root export and type entry;
2. root and `./api` runtime export equivalence;
3. absence of known infrastructure symbols.

## Follow-up

R02 introduces the shared application runtime. It must preserve this boundary and must not reintroduce infrastructure exports.
