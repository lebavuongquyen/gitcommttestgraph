# 0.10.2 O06 — Diagnostic Bundle

Date: 2026-10-07
Status: IMPLEMENTED

## Goal

O06 produces one machine-readable, secret-safe diagnostic bundle for support, reproducibility and operational inspection.

## Bundle contents

- bundle schema version;
- generation timestamp;
- GCTG version;
- Node version;
- operating-system platform and architecture;
- current Git HEAD;
- aggregated health;
- bounded operation history;
- effective configuration provenance;
- snapshot storage accounting.

## Reproducibility

The bundle records environment and repository identity needed to reproduce a reported state without embedding secrets.

## Security

Configuration already passes through the sensitive-configuration boundary.

Operation history is loaded through the secret-safe bounded history service.

No credentials, environment secrets or GitHub tokens are collected by the bundle.

## Surfaces

HTTP: GET /api/diagnostic-bundle

MCP: diagnostic_bundle

## Scope boundary

O06 does not create a telemetry backend, upload diagnostics automatically, collect system logs or perform repair.

## Tests

Coverage includes machine-readable bundle shape and HTTP/MCP callable contracts.
