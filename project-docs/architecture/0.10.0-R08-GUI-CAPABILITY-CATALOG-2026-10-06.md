# R08 - Complete GUI Capability Catalog

Date: 2026-10-06

## Objective

Close the remaining GUI capability-boundary gap identified after R07: browser routes that existed in the controller but were not represented by the typed GUI capability catalog.

## Changes

- Expanded `GuiCapabilityId` to cover every GUI API route currently used by the browser controller.
- Added descriptors for commits, branches, node inspection, execution feedback, execution-plan execution, overview, and graph view.
- Re-exported the presentation ViewModel types from the GUI contract entrypoint.
- Added lightweight presentation ViewModel contracts for secondary panels so future adapters have an explicit target shape.
- Added an R08 contract test that compares the typed capability catalog against every browser route and rejects duplicate ids/paths.

## Result

The GUI now has one explicit capability catalog covering all 20 browser API paths. R07 normalization remains unchanged for the primary status, commits, graph, execution, and change-intelligence panels.
