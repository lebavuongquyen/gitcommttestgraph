# 0.10.0 R03 — Capability Surface Conformance

Date: 2026-10-06
Baseline: v0.9.8

## Objective

Turn cross-surface parity from a manual convention into an executable architecture rule.

## Capability descriptor

Each registered capability declares:

- stable identity;
- application handler;
- applicable GUI surface;
- applicable MCP surface;
- applicable CLI surface;
- applicable HTTP surface;
- applicable public API surface where externally supported.

The registry does not generate surface code. It detects drift.

## Conformance rule

For every declared surface, the registered marker must be present in the corresponding adapter. A missing marker fails the contract gate.

## Defect caught during implementation

The first conformance run identified that `test_gaps` existed in application, CLI, HTTP and MCP but was not represented in the GUI.

This is the exact class of parity regression R03 is intended to catch.

The GUI was updated to display test-gap analysis while preserving the existing change-intelligence GUI contract.
