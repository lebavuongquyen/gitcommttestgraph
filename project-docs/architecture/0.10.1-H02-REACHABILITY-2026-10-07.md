# H02 — Reachability Analyzer

Date: 2026-10-07

## Goal

H02 answers one narrow question:

Can we prove that a commit is still reachable from a current branch or explicitly protected by evidence?

The analyzer is deliberately conservative.

If reachability cannot be proven, it does not convert that uncertainty into permission to delete anything.

## How it works

For each requested commit:

1. Current branch refs are loaded.
2. Git merge-base is checked between the commit and each branch tip.
3. If the commit is the merge-base, the commit is reachable from that branch.
4. Explicit protected evidence can also protect a commit.
5. Every decision contains reasons.

The result is deterministic for the same Git state and evidence.

## Result

Each result contains:

- commit;
- reachable;
- protected;
- reasons.

protected means there is enough evidence to keep the commit protected.

It does not mean that the commit should be deleted when false.

## Safety rule

H02 follows the 0.10 rule:

**absence of proof is not proof of safety.**

An unknown or unavailable branch relationship is recorded as uncertainty. Later cleanup planning must treat such uncertainty conservatively.

## Surfaces

H02 is exposed through:

- HTTP: /api/reachability?commits=<comma-separated commits>
- MCP: reachability

The service remains read-only.

## Scope boundary

H02 does not yet:

- calculate retention age;
- evaluate quotas;
- inspect release metadata;
- inspect pull-request evidence automatically;
- delete snapshots;
- mutate Git.

Those responsibilities belong to later H03-H05 work.

## Tests

The focused tests verify:

- branch reachability protects a commit;
- explicit protection evidence protects an otherwise unreachable commit;
- duplicate inputs are removed;
- output ordering is deterministic.

## Definition of Done

- [x] deterministic reachability service exists;
- [x] current branch refs are supported;
- [x] explicit protection evidence is supported;
- [x] uncertainty is preserved;
- [x] HTTP exposure exists;
- [x] MCP exposure exists;
- [x] tests and documentation exist.
