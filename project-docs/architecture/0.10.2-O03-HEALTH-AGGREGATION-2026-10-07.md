# O03 — Health Aggregation

Date: 2026-10-07

## Goal

O03 provides one small read-only health report for the running GCTG instance.

It combines a few high-value checks instead of creating a large monitoring framework.

## Checks

The current report checks:

- Git access and current HEAD;
- GCTG snapshot storage access;
- failed runtime operations.

Overall status is:

- HEALTHY;
- DEGRADED;
- UNHEALTHY.

## Mental model

Health answers:

“Can the system currently perform its basic work?”

It does not replace diagnostics or operation history.

## Surfaces

Health is exposed through:

- HTTP: /api/health
- MCP: health

## Scope boundary

O03 does not:

- send alerts;
- run background monitoring;
- expose infrastructure secrets;
- replace CI health;
- make automatic repairs.

## Tests

Tests cover healthy and degraded reports.

## Definition of Done

- [x] Git health is checked;
- [x] storage health is checked;
- [x] failed operations affect health;
- [x] overall status is deterministic;
- [x] HTTP and MCP exposure exists;
- [x] tests and documentation exist.
