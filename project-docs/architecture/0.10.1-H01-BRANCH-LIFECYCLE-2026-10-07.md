# H01 — Branch Lifecycle Model

Date: 2026-10-07

## Goal

H01 observes branch lifecycle evidence without changing Git history.

The simple mental model:

- current branch refs tell us what exists now;
- reflog evidence tells us what Git recorded about earlier branch activity;
- a deleted branch is historical evidence, not a current ref;
- a recreated branch is treated as lifecycle evidence rather than silently merged with its earlier identity.

## Application contract

BranchLifecycleService returns:

- current — current branch references;
- evidence — available lifecycle evidence;
- deleted — evidence classified as deleted;
- recreated — evidence classified as recreated.

The service is read-only.

## Evidence source

The Git adapter uses reflog output when available.

Reflog availability can differ by repository configuration and retention. Therefore absence of reflog evidence does not prove that a branch never existed.

This is important for later retention decisions: missing evidence must not become permission to delete protected state.

## Surfaces

H01 is exposed through:

- HTTP: /api/branch-lifecycle
- MCP: branch_lifecycle

The feature is intentionally not added to the GUI catalog yet. The existing GUI already provides branch review; H01 will be integrated into the GUI when the lifecycle/retention workflow is ready rather than creating a second disconnected branch UI.

## Scope boundary

H01 does not:

- delete branches;
- rewrite Git history;
- decide whether a snapshot is safe to remove;
- calculate retention eligibility;
- infer lifecycle facts when Git provides no evidence.

Those decisions belong to H02-H04.

## Tests

Tests cover:

- current refs;
- deleted evidence;
- recreated evidence;
- operation when reflog evidence is unavailable.

## Definition of Done

- [x] branch lifecycle domain evidence exists;
