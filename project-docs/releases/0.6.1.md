# Release 0.6.1

Date: 2026-10-06

## Release goal

Harden Branch Intelligence without introducing a new product capability or changing the public contract of the 0.6.x line.

## Delivered

- Semantic graph diff now detects edge-only changes and resolves their affected symbols.
- Deleted-symbol detection distinguishes true removals from line-shifted or moved symbols.
- Local variable churn is excluded from deleted-symbol risk escalation.
- Branch ChangeSet includes per-commit change evidence while remaining backward-compatible for existing ChangeSet consumers.
- Branch Review exposes removed-symbol evidence and commit-level evidence to GUI, HTTP and MCP consumers.
- GUI Branch Intelligence now shows merge-base, removed symbols and per-commit evidence.
- Added regression coverage for edge-only changes, deleted symbols, line shifts and removed-symbol review risk.
- Existing 0.6.0 behavior remains available; this release hardens the implementation.

## Compatibility

No required public TypeScript fields were added to existing ChangeSet or BranchReview contracts. New evidence fields are optional for compatibility.
