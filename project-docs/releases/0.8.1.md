# Release 0.8.1

Date: 2026-10-06

## Purpose

0.8.1 hardens the public contract introduced by 0.8.0.

The release follows the mandatory development rule:

> No Surface Without Gate.

The Change Intelligence capability remains deterministic and application-owned while each exposed surface receives explicit contract validation.

## Scope

### CLI

- `gctg change-intelligence` validates the source selector.
- Invalid source values return usage diagnostics with exit code 2.
- Repeated default queries produce equivalent deterministic JSON.

### HTTP/API

- `GET /api/change-intelligence` rejects invalid `source` values with HTTP 400.
- JSON content type remains explicit.
- Successful responses preserve the existing schema envelope.

### MCP

- `change_intelligence` advertises the constrained `COMMIT | BRANCH` source schema.
- Invocation remains read-only and deterministic.
- Contract tests verify the public result envelope.

### GUI

- Change Intelligence is now actually captured from the sixth API request in the commit-loading workflow.
- GUI commit loading has an explicit error state instead of silently losing the intelligence result.
- The real HTTP GUI gate verifies the Change Intelligence fetch path.
