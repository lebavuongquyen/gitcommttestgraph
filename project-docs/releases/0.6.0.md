# Release 0.6.0

Date: 2026-10-06

## Release goal

Deliver Branch Intelligence as a complete GUI-first capability that normalizes a Git branch into a ChangeSet and produces a deterministic merge-readiness review from code impact, test impact, test gaps and execution planning.

## Delivered

- Git branch discovery with current-branch and remote metadata.
- Deterministic merge-base resolution.
- Ordered commits unique to a branch.
- Branch ChangeSet domain model.
- Branch ChangeSet application service.
- Branch review decision model with READY, NEEDS_REVIEW, HIGH_RISK, BLOCKED and INCONCLUSIVE outcomes.
- Risk classification and explicit reasons/uncertainty.
- Changed-symbol and downstream-symbol analysis across the branch range.
- Aggregated test-gap and test-impact analysis for the branch.
- Deterministic impacted-test execution plan for the branch.
- GUI branch base/head selectors and visual review cockpit.
- HTTP branch listing and branch-review endpoints.
- MCP tools for branch listing and branch review.
- CLI commands for branch listing and branch review.
- Automated tests for branch ancestry, ChangeSet normalization and review decisions.

## Decision flow

Base Branch
    ↓
Merge Base
    ↓
Branch Commits
    ↓
Changed Symbols
    ↓
Downstream Impact
    ↓
Test Gaps + Test Impact
    ↓
Execution Plan
    ↓
Risk + Review Decision

## MCP alignment

The branch feature is exposed through the same application/domain services used by the GUI and CLI:
- `branches` lists branch metadata.
- `branch_review` produces the deterministic branch review.

MCP remains an adapter boundary and contains no branch-review business rules.

## GUI acceptance

The GUI provides:
- Base branch selector.
- Head branch selector.
- Explicit `Review branch` action.
- Decision and risk display.
- Commit count and merge-base visibility.
- Changed/affected symbol counts.
- Impacted test count.
- Reasons and uncertainty visibility.
